The REST reference lists every endpoint, grouped by resource, with its parameters and response shape. You can send requests from it with your own token.

**[Open the REST reference →](https://api.sesami.co/swagger)**

All paths sit under `https://api.sesami.co/api/v1`, and most are scoped to a shop: `/api/v1/{shop}/...`. Send the [authentication headers](../3-concepts/1-authentication.mdx) with every request.
